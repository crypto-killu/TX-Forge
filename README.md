## ✨ Что внутри

| Актив | Как работает |
|---|---|
| 🔷 **GRAM (TON)** | Обычная ссылка перевода `ton://transfer/<адрес>?amount=<сумма>` |
| 🟠 **Bitcoin** | Через wrapped-jetton на TON — см. [важное предупреждение](#-важно-про-bitcoin) ниже |
| 💵 **USDT** | Через официальный USDT jetton-контракт на TON |
| 🎁 **NFT актив** | Закодированное TEP-62 transfer-сообщение — ссылка открывает в Tonkeeper уже готовый к подтверждению перевод конкретного NFT-подарка |

Все ссылки открываются прямо в Tonkeeper (и большинстве других TON-кошельков) с уже подставленными данными — получателю остаётся только подтвердить перевод.

## 🎮 Как пользоваться

1. Запусти `node index.js`
2. Выбери **1. Создать платёжную ссылку**
3. Введи TON-адрес получателя
4. Выбери актив (1–4)
5. Укажи сумму (для TON / BTC / USDT) или адрес NFT-контракта
6. Получи готовую ссылку — кидай её кому угодно

После каждой ссылки можно сразу создать следующую на тот же адрес или вернуться в меню — не нужно перезапускать программу заново.

## ⚠️ Важно про Bitcoin

На TON-блокчейне **нет нативного Bitcoin** — есть только **обёрнутые (wrapped)** токены, представляющие BTC через jetton-контракт. В TXFORGE это реализовано как обычный jetton-перевод (как и USDT), а **не** как реальная Bitcoin-транзакция.

**Перед использованием в проде обязательно проверь актуальный адрес jetton-мастера на [tonviewer.com](https://tonviewer.com)** — зашитый в коде адрес лишь пример, мостов несколько, и под одно и то же название ("wrapped BTC") существуют разные контракты. Fake jetton-токены с тем же именем/логотипом — частый вид мошенничества, единственный надёжный идентификатор — именно адрес master-контракта.

## 🛠 Требования

- **Node.js 18+**
- Интернет при первом запуске (для самоустановки `@ton/core`)

## 📦 Технические детали

- Единый файл `index.js` — весь интерфейс (баннер, меню, генерация ссылок) в одном месте
- Самоустановка через `npm install`, запускается автоматически при отсутствии `node_modules`
- Генерация NFT-ссылок — через `@ton/core`, ручная сборка BOC-сообщения по стандарту TEP-62
- Никаких внешних API-запросов для генерации ссылок — всё считается локально
