## 🚀 Быстрый старт

```bash
git clone <твой-репозиторий>
cd txforge
node index.js
```

Вот и всё. Зависимости не нужно ставить руками — **TX-Forge сам всё установит** при первом запуске в терминале. Просто клонируй и запускай.

---

Все ссылки открываются прямо в Tonkeeper (и большинстве других TON-кошельков) с уже подставленными данными — получателю остаётся только подтвердить перевод.

## 🎮 Как пользоваться

1. Запусти `node index.js`
2. Выбери **1. Создать платёжную ссылку**
3. Введи TON-адрес получателя
4. Выбери актив (1–3)
5. Укажи сумму (для TON / USDT) или адрес NFT-контракта
6. Получи готовую ссылку

## 🛠 Требования

- **Node.js 18+**
- Интернет при первом запуске (для самоустановки `@ton/core`)
